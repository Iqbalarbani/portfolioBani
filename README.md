# Personal Portfolio - Iqbal

Website portofolio pribadi berbasis HTML5, CSS3, dan Vanilla JavaScript yang ringan, responsif, dan siap di-deploy ke Cloudflare Pages, Vercel, atau GitHub Pages.

## Struktur File
- `index.html` - Struktur halaman utama (Hero, Proyek Unggulan, Pengalaman, Keahlian, Kontak)
- `styles.css` - Styling responsif dengan dukungan tema gelap dan terang
- `script.js` - Pengaturan tema, navigasi mobile, dan tahun otomatis

## Cara Menjalankan Lokal
Buka `index.html` langsung di browser atau gunakan ekstensi **Live Server** di VS Code.
